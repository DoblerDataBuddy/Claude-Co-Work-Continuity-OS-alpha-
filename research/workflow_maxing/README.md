# Workflow Maxing Research

Strategies for optimizing AI/human collaboration under the continuity system.

## Research Questions

### Context Windows
- How to fit most useful context in a given token budget?
- What's the tradeoff between breadth and depth of context?
- Which files/docs are actually used in decision-making?
- How does context freshness affect outcomes?

### Session Design
- Optimal session length for continuity overhead?
- Best handoff points for multi-role workflows?
- How to minimize context-switching cost?
- Can workflows be designed to exploit continuity?

### Human Participation
- Where does human input have highest ROI?
- How to structure async workflows across time zones?
- What decisions must be made by humans vs. AI?
- How does continuity change the nature of async collaboration?

## ERAU Student Workflow
[HYPOTHESIS] Student workflow optimization:
- Assignment deadline pressure creates natural session boundaries
- Continuity reduces "ramp-up" time on next study session
- Token savings enable longer/deeper reasoning within limited quota
- Could scale to other time-constrained workflows

Origin context: This system started from optimizing undergraduate coursework under time pressure.

## Experiments
- Track real workflows to find patterns
- Measure time-to-productive-work with/without continuity

- Extrapolate to other use cases
