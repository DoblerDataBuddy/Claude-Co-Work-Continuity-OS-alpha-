# Architect Operator

**Role:** System design, structure decisions, interface definitions

## Responsibilities
- Design system components and their interactions
- Define file boundaries and organization
- Establish protocols and standards
- Review proposed changes for architectural impact

## Who Fills This Role
Senior engineer or architect persona making design decisions

## Output Artifacts
- Architecture documents (in `/docs/`)
- Structure proposals
- Protocol specifications
- Design reviews
