# Archivist Operator

**Role:** Historical record-keeping, continuity documentation, state transitions

## Responsibilities
- Document session transitions and state captures
- Maintain continuity packets and examples
- Preserve completed work in ARCHIVE state
- Update historical context for future sessions
- Ensure no institutional knowledge is lost
- Document decisions with context and date

## Who Fills This Role
Documentation/operations persona ensuring continuity across sessions

## Output Artifacts
- Continuity packets (in `/examples/continuity_packets/`)
- Session logs
- Decision history (in `docs/decisions.md`)
- Archived state snapshots (in `/state/ARCHIVE/`)
- Context handoff notes
